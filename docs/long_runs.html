Rewarding Doubt · Llama-3-8B · TriviaQA · dev, 512 questions

Long-run calibration curves

Each line is one training seed, scored on the 512-question dev split every 500 steps, starting from the base model at step 0. Training uses the full TriviaQA training set at learning rate 1e-5 with the paper's KL controller and −30 for malformed output; the arms differ only in the update rule. Lower Brier and ECE are better; higher AUROC is better.

  • Paper marks Rewarding Doubt's published result: ECE 0.0226 and AUROC 0.8592 on the full TriviaQA test split (11,313 questions) after about 21,900 steps. It is a reference level, not a point on these axes; our curves stop at 4,000 steps and are measured on dev.
  • The shaded band in the ECE chart is where a perfectly calibrated model with our confidence spread lands on 512 questions (mean 0.036, 95% range 0.019–0.061). Below about 0.04, differences in ECE here are noise. At the paper's test size the band sits near 0.008.
  • Frozen runs (solid) generate answers with the adapter off and are scored the same way; on-policy runs (dashed) generate answers with the adapter and use the released evaluation. Exact + hinge was only run on-policy.
  • PPO + KL frozen seed 1 ran out of memory on a 24 GB GPU at step 951; seed 2's step-1,500 and step-4,000 scores are being recomputed after an evaluator fix. On-policy PPO also stopped early for memory (steps 2,138 and 1,374).
